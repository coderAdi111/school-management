\# 🏫 School Management System



A full-stack School Management System designed to manage students, teachers, classes, attendance, fees, and marks from a single dashboard.



\## 🚀 Features



\### 📊 Dashboard

\- Total Students

\- Total Classes

\- Fee Records

\- Mark Records

\- Attendance Summary

\- Fee Status Summary



\### 👨‍🎓 Student Management

\- Add Student

\- Edit Student

\- Delete Student

\- Assign Student to Class

\- Manage student information



\### 👨‍🏫 Teacher Management

\- Add Teacher

\- Edit Teacher

\- Delete Teacher

\- Subject management

\- Qualification management

\- Teacher status management



\### 🏫 Class Management

\- Add Class

\- Edit Class

\- Delete Class

\- Assign Teacher to Class

\- Manage Class Capacity



\### 📅 Attendance Management

\- Add Attendance

\- Edit Attendance

\- Delete Attendance

\- Attendance status:

&#x20; - Present

&#x20; - Absent

&#x20; - Late

&#x20; - Excused



\### 💰 Fee Management

\- Add Fee Record

\- Edit Fee Record

\- Delete Fee Record

\- Track fee status:

&#x20; - Pending

&#x20; - Paid

&#x20; - Overdue

&#x20; - Waived



\### 📝 Marks Management

\- Add Marks

\- Edit Marks

\- Delete Marks

\- Subject-wise marks

\- Exam type

\- Total marks

\- Obtained marks

\- Percentage and Grade
